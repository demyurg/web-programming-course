# Веб-программирование

Публичные материалы курса собраны по занятиям. Для каждого занятия доступны задание и справочные материалы, необходимые для самостоятельной работы.

## С чего начать

Сейчас опубликовано нулевое занятие:

[Открыть задание нулевого занятия](lessons/l0/README.md)

В нём есть стартовая практика по HTML, CSS и JavaScript, а также материалы для подготовки и самостоятельной работы.

Первый шаг:

1. Прочитайте README нулевого занятия.
2. Ознакомьтесь с [гайдом по Git и GitHub](docs/GITHUB_GUIDE.md).
3. После лекции выполните задание и подготовьте результат к сдаче.

## Формат работы

Каждое занятие состоит из лекционной встречи и самостоятельной практики.

После лекции выдаётся задание по прошедшей теме. К следующей встрече студент сдаёт результат. На практической встрече разбираются выполненные работы, типовые ошибки и вопросы.

## Как сдавать работу

Рабочий процесс курса:

~~~text
fork → clone → ветка задания → commit → push → pull request
~~~

Подробная инструкция находится в [гайде по Git и GitHub](docs/GITHUB_GUIDE.md).
