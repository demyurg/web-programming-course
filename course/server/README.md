# Учебный API

Локальный сервер для учебного тренажёра. Он реализует контракт из [`course/CONTRACT.md`](../CONTRACT.md) на встроенном HTTP-модуле Node.js и слушает `http://localhost:3001`. Для A6 он предлагает базовый и повышенный учебные модули и принимает демонстрационный код `DEMO-A6` в заголовке `X-Access-Code`.

## Запуск

Из корня репозитория:

```sh
node course/server/server.mjs
```

Команды одинаковы для Linux/macOS и Windows PowerShell. Данные модулей загружаются из [`training-set.json`](../data/training-set.json) и [`training-set-advanced.json`](../data/training-set-advanced.json). Старый путь A5 по-прежнему отдаёт первый модуль.

## Ограничения

- Сервер учебный и не предназначен для production или официального тестирования.
- Демонстрационный код проверяет клиентский обмен, но не устанавливает личность студента. Старый открытый путь A5 с `{setId}` продолжает работать.
- Попытки хранятся ephemeral — только в памяти процесса и исчезают после перезапуска.
- Сервер не предоставляет ручное оценивание ответов `short-text`; такие ответы получают `pending-review`.
- Для A6 доступны два модуля: базовый с четырьмя заданиями и повышенный с тремя. `GET /api/available-sets` отдаёт только названия и число заданий; выбранный модуль закрепляется за попыткой. Персональный список модулей предоставляет отдельный контрольный сервер.
- Официальные ключи, временные персональные коды и закрытый банк заданий не входят в репозиторий.

## Учебная ошибка

Для проверки обработки ошибки добавьте к API-запросу заголовок `X-Demo-Fail: 1`. Сервер вернёт HTTP 500 и не изменит состояние данных. После этого уберите заголовок и повторите запрос.

Подробные маршруты, форматы JSON, правила валидации и статусы ответов описаны в [`course/CONTRACT.md`](../CONTRACT.md).
