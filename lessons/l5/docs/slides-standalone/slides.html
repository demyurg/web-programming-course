Правила каталога

Адрес /books/42, поле bookId, значение ошибок.

200 означает успешный HTTP-ответ; пригодность данных клиент проверяет отдельно.

REST — подход к устройству сервиса вокруг ресурсов; HTTP API не обязательно следует ему полностью.

Сначала описание

Описание API → реализация сервера и клиента

Сначала код

Реализация сервера → описание API

OpenAPI — стандартный формат описания HTTP API. Orval создаёт по нему типы и функции клиента.

В обоих случаях описание сверяют с работой сервера.

Другие способы договориться

WebSocket

Обе стороны посылают сообщения в установленной связи. Например, совместное редактирование.

gRPC

Описанные вызовы и типы между службами. Обычно работает поверх HTTP/2.

Каждый способ требует обработки разрыва связи и ошибок.
