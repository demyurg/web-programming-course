# Учебный тренажёр: A1–A3

Приложение позволяет пройти локальную попытку по учебному модулю из `course/data/training-set.json`. Ответы хранятся только в состоянии React и сбрасываются при перезагрузке страницы или явном начале новой попытки.

## Запуск

Из папки `trainer/`:

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Проверка модели и сборки:

```sh
npm run check
npm run demo
npm run build
```

## Устройство

- `src/domain.ts` — типы и функции модели A1.
- `src/App.tsx` — состояние ответов по `Task.id`, навигация, производный прогресс, подтверждение завершения и обзор.
- `src/components/TaskCard.tsx` — условие задания и контролируемые поля ответа.
- `src/components/TaskList.tsx` — переход к заданию и статус его заполнения.
- `src/styles.css` — оформление и адаптация для узких экранов.

Пробельный текст считается незаполненным. Обзор завершённой попытки показывается под заданиями; их можно просмотреть, а для редактирования нужно явно начать новую. Сервер, оценивание и сохранение между перезагрузками не используются.

## Проверка сценария

1. Выберите вариант ответа, откройте текстовое задание и введите текст; вернитесь и измените вариант.
2. Убедитесь, что ответы сохраняются при переходах, а прогресс меняется, в том числе при замене текста пробелами.
3. Завершите попытку с пропуском, отмените предупреждение и проверьте ответы. Затем подтвердите завершение.
4. Проверьте обзор и начните новую попытку: поля и прогресс должны сброситься.
