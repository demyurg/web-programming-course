# Учебный тренажёр: A1–A4

Приложение позволяет пройти локальную попытку по учебному модулю из `course/data/training-set.json`. Все ответы видны в обзоре во время прохождения. Ответы, текущее задание и статус восстанавливаются после перезагрузки страницы из локального хранилища браузера.

## Запуск

Из папки `trainer/`:

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Проверка модели и сборки:

```sh
npm run check
npm run demo
npm run build
```

## Устройство

- `src/domain.ts` — типы и функции модели A1.
- `src/attempt.ts` — reducer попытки, формат черновика и проверка сохранённых данных.
- `src/App.tsx` — синхронизация с хранилищем через эффекты, навигация, производный прогресс, подтверждение завершения и обзор.
- `src/components/TaskCard.tsx` — условие задания и контролируемые поля ответа.
- `src/components/TaskList.tsx` — переход к заданию и статус его заполнения.
- `src/styles.css` — оформление и адаптация для узких экранов.

Кнопки «Очистить ответ» в карточке и обзоре отправляют одно событие `answerCleared` с идентификатором задания. Reducer удаляет ответ из массива попытки. Карточка, обзор, прогресс и список пропусков обновляются по этому массиву. После `submitted` reducer отклоняет изменение и удаление ответов, а интерфейс отключает поля и убирает кнопки очистки.

Пробельный текст считается незаполненным. Завершённая попытка восстанавливается в режиме просмотра. Кнопка «Начать новую попытку» сбрасывает ответы и открывает первое задание.

Черновик хранится в `localStorage` под ключом `web-programming-course:trainer:draft`. Перед восстановлением проверяются версия, набор, выбранное задание и ответы, включая типы и идентификаторы вариантов. Повреждённая запись или черновик другого набора сохраняются до явного сброса. При ошибке чтения или записи можно продолжать отвечать в памяти страницы.

## Проверка сценария

1. Выберите вариант ответа, откройте текстовое задание и введите текст; вернитесь и измените вариант.
2. Проверьте оба ответа в обзоре до завершения. Очистите ответ сначала из карточки, затем введите его снова и очистите из обзора. В обоих случаях ответ должен исчезнуть из карточки и обзора, а задание — появиться в списке пропусков. Введите ответ снова перед следующим шагом.
3. На текстовом задании перезагрузите страницу. Должны восстановиться выбранное задание, оба ответа и прогресс.
4. Завершите попытку и снова перезагрузите страницу. Проверьте обзор и недоступность редактирования. Начните новую попытку и проверьте сброс после перезагрузки.
5. В DevTools замените сохранённое значение на `{`, перезагрузите страницу и проверьте сообщение и кнопку «Сбросить черновик». Повторите с корректной записью, у которой изменён `setId`.
6. Запретите сайту пользоваться локальным хранилищем и перезагрузите страницу. Должно появиться предупреждение, при этом ввод и навигация остаются доступны.
