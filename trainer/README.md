# Тренажёр веб-программирования

В папке `trainer/` находится клиент на React, TypeScript и Vite. Для ЛР5 ему нужен учебный сервер из этого же репозитория.

## Запуск

В первом терминале из корня репозитория:

```powershell
node course/server/server.mjs
```

Сервер отвечает на `http://localhost:3001`. Во втором терминале:

```powershell
cd trainer
npm install
npm run dev
```

Откройте адрес, который показывает Vite (обычно `http://localhost:5173`). Для проверки сборки из `trainer/` выполните `npm run build`.

## Проверка ЛР5

Создайте попытку, выберите ответ и нажмите «Сохранить ответ на сервере». Выбор в карточке сначала меняет локальный ввод; подтверждение появляется только после успешного PUT. Кнопка очистки отправляет DELETE. Завершение отправляет пустой объект `{}` и показывает результат сервера. Текстовый ответ получает статус «Ожидает проверки», а не нулевую оценку.

Для проверки обработки HTTP 500 отметьте «Проверить ошибку сервера при следующем сохранении», сохраните ответ и затем нажмите «Повторить запрос». При ошибке ввод остаётся на экране. Запросы видны в инструментах разработчика браузера на вкладке Network.

Браузер хранит только `attemptId`; после обновления подтверждённая попытка запрашивается у сервера. Сервер хранит попытки в памяти: его перезапуск удаляет их, после чего интерфейс предложит создать новую попытку.

`npm run demo` запускает отдельную консольную демонстрацию функций из ЛР1 и не открывает браузерный тренажёр.

## Продолжение курса

После ЛР5 приложение остаётся в папке `trainer/`. Следующая лабораторная работа, ЛР6, добавляет Vitest и React Testing Library; до её выполнения `npm test` не требуется. Рабочую точку каждого этапа фиксируйте коммитом и создавайте следующую ветку от версии с предыдущей лабораторной работой. Материалы и порядок сдачи находятся в [описании курса](../course/README.md).
